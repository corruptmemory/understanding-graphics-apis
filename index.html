Working an exercise

Everything runs through the build program, from the repo root:

~/jai/jai/bin/jai-linux first.jai - build   vulkan/exercise-3   # compile the windowed program
~/jai/jai/bin/jai-linux first.jai - run     vulkan/exercise-3   # build, then look at it
~/jai/jai/bin/jai-linux first.jai - test    vulkan/exercise-3   # the headless gate: pixels and zero validation errors
~/jai/jai/bin/jai-linux first.jai - capture vulkan/project-1    # a PNG of the last readback, for grading
